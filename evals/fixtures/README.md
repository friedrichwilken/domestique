# fixtures are synthetic or anonymised; never real athlete data

- `claims_seed.yaml`: the synthetic athlete model (task 003), with bindings where a claim maps
  onto a predicted metric. Loaded by `domestique.claims.seed`.
- `season_a/`: a 12-week synthetic season for the replay eval, with a planted effect (a hard
  session in the evening costs about an hour of sleep that night). Generated by
  `python evals/fixtures/season_a/generate.py` with a fixed seed; regeneration is byte-identical
  and tested. Rides are run-length-encoded streams (`[seconds, watts, hr]` blocks).
- The replay starts from `evals/priors.yaml` (textbook priors only), not from a fixture.
